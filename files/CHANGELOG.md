# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2024-01-15

### Added
- Complete rewrite with C++17 standard
- Object-Oriented Design with Sudoku and FileManager classes
- Recursive backtracking solver with optimization
- Step-by-step solving animation
- Puzzle generator with unique solution guarantee
- Hint system
- Difficulty detection (Easy, Medium, Hard, Expert)
- Statistics tracking (solve time, recursive calls, backtracks)
- Light/Dark theme support
- Keyboard shortcuts
- User profiles with persistent data
- Leaderboard (Top 10 fastest solves)
- History tracking with timestamps
- Comprehensive logging system
- Undo/Redo functionality
- ANSI-colored console UI
- Input validation and error handling
- Configuration file management
- Sample puzzle file
- Extensive documentation
- GitHub-ready project structure

### Changed
- Complete architecture redesign
- Enhanced algorithm efficiency
- Better error messages and logging

### Fixed
- Memory leaks from previous versions
- Thread safety issues
- File format inconsistencies

## [1.0.0] - 2023-06-01

### Added
- Initial release
- Basic Sudoku solver
- Console interface
- File loading
- Solution saving
